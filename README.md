# Gemstones

Discover 12 unique gemstones:

- Ruby
- Sapphire
- Green Sapphire
- Blue Garnet
- Pink Garnet
- Green Garnet
- Kyawthuite
- Topaz
- White Topaz
- Peridot
- Jade
- Pyrope

Each gemstone includes:
- Ore and Deepslate Ore variants
- Raw gemstone variants
- Polishing support using the Gem Purifier

# Crafting

## Energy Block
- Can be crafted by surrounding TNT with Radiants
- Energy Block can be used to obtain 9 Energy Ingots

## Radiant
- Can be crafted by surrounding a Diamond with Ruby Blocks

---

# Armor & Tools

Craft and upgrade powerful equipment sets.

## Armor Sets
- Ruby Armor
- Sapphire Armor

## Tool Sets
- Ruby Tools

# Gem Purifier

Use the **Gem Purifier** to polish raw gemstones into refined variants.

## Features
- Energy handling system
- Dedicated input/output slots
- Fuel support
- Additional storage slots

## Supported Fuel
- Energy Ingots
- Energy Blocks

Learn how to use the Gem Purifier:
